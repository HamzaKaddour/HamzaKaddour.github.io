Global Development Intelligence Platform

A zero-cost, source-aware public-data product that turns World Bank and IMF data into an auditable global explorer, country intelligence brief, benchmarking engine, and automated analytical pipeline.

DataWorld Bank WDI + IMF WEO
Coverage217 countries/economies
Indicators19 across 6 domains
DeliveryGitHub Pages + Actions
Live productGitHub

Problem

International development data is authoritative but fragmented across institutions, indicators, vintages, and observation types. A dashboard that simply mixes values can be misleading when reported observations and forecasts are visually indistinguishable.

Design decision

I modeled provenance at the metric level. Every displayed value can carry its year, source, and status. World Bank WDI reported observations take precedence; IMF WEO fills selected missing current/future macro values and is labeled estimate/projection.

Architecture

What the product does

  • Large global choropleth as the primary navigation surface
  • Map/table exploration across Economy, People, Poverty & Equity, Climate, Infrastructure, and Digital domains
  • Country briefs, regional/income/global median benchmarking, and progress-since-2015 views
  • Reported-only and estimate/projection filtering
  • Machine-readable data manifest with refresh metadata and provenance rules

Engineering choices

The workload is read-heavy, so a paid database or backend would add operational cost without clear value. GitHub Actions preprocesses authoritative data into Parquet, while the browser performs filtering and visualization. The result is reproducible, low-maintenance, and free to host.

Outcome

The project demonstrates API integration, data modeling, schema harmonization, provenance, geospatial visualization, analytical UX, CI/CD, and production-oriented architectural trade-offs in a single public product.

Evidence

  • 6,580 country-year records in the current multi-source layer
  • 217 countries/economies
  • 2000–2030 history + outlook horizon where data exists
  • 2026 macro outlook explicitly labeled as IMF estimate/projection
  • Automated scheduled refresh

Stack

Python · pandas · PyArrow · requests · Parquet · JavaScript · Plotly.js · GitHub Actions · GitHub Pages

Why it matters

The differentiator is not the number of charts. It is the combination of trustworthy provenance, institutional data, automation, and an interface designed for comparison and decision support.
