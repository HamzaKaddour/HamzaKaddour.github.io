A local-first RAG evaluation platform designed around measurable retrieval quality, grounded generation, citation behavior, abstention, and traceability rather than a one-off chatbot demo.

Problem

RAG systems can appear convincing while failing on retrieval, grounding, citation coverage, or refusal behavior. The project was built to make those failure modes measurable and inspectable.

Architecture

Corpus |---------------------| v v BM25 SentenceTransformers + FAISS | | +----------+----------+ v Hybrid retrieval | CrossEncoder rerank | retrieval-confidence gate | local Qwen | answer + source assignment / \ citation checks groundedness \ / SQLite traces | FastAPI

Evaluation-driven iteration

The project intentionally records benchmark regressions and improvements. Weak citation coverage, grounding, and abstention behavior in earlier iterations led to a retrieval-confidence gate, tighter generation constraints, and deterministic sentence-level source assignment.

Scope discipline

The benchmark is a small, purpose-built regression set. The repository explicitly documents that these numbers demonstrate observability and measured iteration rather than broad production performance.

Outcome

The system demonstrates retrieval engineering, local LLM integration, evaluation semantics, reliability controls, APIs, observability, testing, and transparent benchmark reporting.

Cost model

Designed to run locally without paid LLM APIs, hosted vector databases, or cloud GPUs.
