# Hamza Kaddour — ML / AI Engineering Portfolio

[**Live portfolio → hamzakaddour.github.io**](https://hamzakaddour.github.io/)

A recruiter-facing portfolio centered on production-oriented machine learning, GeoAI, RAG/LLM evaluation, MLOps, data engineering, computer vision, and intelligent systems.

## Flagship work

- **Global Development Intelligence Platform** — World Bank + IMF data engineering, metric-level provenance, Parquet analytics, interactive geospatial exploration, country benchmarking, and automated serverless deployment.
- **RAGOps Evaluation Dashboard** — hybrid retrieval, reranking, local generation, grounding/citation checks, abstention, traces, tests, and benchmark-driven reliability iteration.
- **MLOps Monitoring Dashboard** — MLflow, FastAPI, prediction logging, Evidently drift analysis, Prometheus/Grafana observability, retraining signals, Docker, and CI.
- **SAR River-Ice Segmentation** — Sentinel-1, weak optical supervision, transformer-based segmentation, temporal context, explainability, and Sentinel-1 → NISAR transfer research.
- **Power-Line Detection with YOLO** — multi-model, multi-resolution aerial object-detection benchmarking.
- **Deep RL for Wireless Systems** — DQN/PPO/A2C research for adaptive handover and network decision-making.
